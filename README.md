# 🎮 Traductor de Videojuegos con IA Local

Pipeline integral y modular para la traducción asistida por Inteligencia Artificial local de videojuegos, diseñado para múltiples motores (**RPG Maker MV/MZ**, **Ren'Py**, **Unity / XUnity**, **GameMaker**, entre otros).

Utiliza Modelos de Lenguaje (LLMs) ejecutados en local mediante **Ollama** para la traducción en tiempo real, junto con un entorno de **Fine-Tuning con Unsloth** para entrenar modelos especializados en jerga de videojuegos, conservación de códigos de escape y coherencia contextual.

## 🚀 Flujo de Trabajo Principal

La tubería de traducción está organizada en pasos numerados para garantizar coherencia y control de calidad:

### 1. `1_traducir_juego.py`
Envía los textos del juego a la IA local (vía Ollama).
* Soporta reanudación automática si se detiene la ejecución.
* Genera copias de seguridad automáticas (`.bak`) de los archivos del juego.
* Respeta variables de formato y códigos de escape del motor.

### 2. `2_generar_revision.py`
Compara el archivo traducido con el original en inglés y genera un CSV estructurado (`revision_<juego>.csv`) con columnas: `tag`, `ingles`, `espanol_ia` y `correccion`. Permite revisar y editar rápidamente en Excel o LibreOffice.

### 3. `3_reparar_etiquetas_ia.py`
Inspecciona la traducción en busca de errores sintácticos comunes de los LLMs:
* Etiquetas de color rotas o alteradas (ej: `\C[1]`, `\c[0]`).
* Variables de texto modificadas (ej: `{Player}`, `%1`, `\V[n]`, `\N[n]`).
* Restaura automáticamente las etiquetas al formato original del motor.

### 4. `4_aplicar_parches.py`
Inyecta tus correcciones en los archivos finales del juego:
* Aplica las filas editadas en la columna `correccion` del archivo de revisión.
* Aplica diccionarios globales de términos (`--diccionario`).
* Con la opción `--resetear`, devuelve al inglés únicamente las líneas problemáticas para que el paso 1 vuelva a traducirlas con un modelo mejorado.

### 5. `5_traducir_nombres_personajes.py`
Detecta los nombres de los personajes que hablan en los diálogos y aplica un glosario unificado para evitar que un mismo personaje aparezca traducido de formas distintas (ej: *Guild Staff* ➔ *Recepcionista del gremio*).

### 6. `6_auditoria_semantica.py`
Auditor de coherencia y falsos amigos. Corrige automáticamente errores típicos de traducción literal en videojuegos:
* `party` ➔ **grupo** (en lugar de *fiesta*).
* `item` ➔ **objeto** (en lugar de *elemento* o *artículo*).
* `save` ➔ **guardar** (en lugar de *ahorrar*).
* `miss` ➔ **fallo** (en lugar de *señorita*).
* `chest` (contenedor) ➔ **cofre** (en lugar de *pecho*).

### 7. `7_arreglar_partida_rpgmaker.py`
Herramienta de descompresión y edición en caliente de partidas guardadas de RPG Maker (`.rpgsave`):
* Descomprime el formato LZ-String en memoria.
* Aplica los reemplazos semánticos directamente en la partida guardada.
* Vuelve a comprimir la partida, permitiendo **probar las correcciones de inmediato sin tener que empezar una nueva partida**.

## 🛠️ Herramientas Extra y Minería de Datos

Ubicadas en la carpeta `herramientas_extra/`:

* **`app.py` y `dashboard.html`**: Servidor local Flask y panel de control web visual para monitorizar el progreso de la traducción, ver líneas traducidas por minuto y gestionar parches desde el navegador.
* **`extraer_textos_renpy.py`**: Extrae diálogos bilingües de juegos de Ren'Py (requiere que los archivos `.rpyc` hayan sido descompilados con *unrpyc*).
* **`extraer_textos_xunity.py`**: Parsea el archivo `AutoGeneratedTranslations.txt` generado por el plugin **XUnity.AutoTranslator** en juegos de Unity.
* **`extraer_textos_juego.py`**: Extractor para carpetas de localización tipo `Langs/` en GameMaker.
* **`traducir_restos.py` y `reanudar_traduccion.py`**: Utilidades para reanudar lotes pendientes o incompletos.
* **`fix_audio.py`**: Utilidad de normalización o reparación de pistas de voz/efectos si el juego lo requiere.

## 🧠 Entrenamiento de la IA (Fine-Tuning con Unsloth)

Para conseguir una traducción con calidad nativa y que no cometa errores con los códigos de control, el pipeline permite reentrenar modelos LLaMA / Mistral mediante LoRA y cuantizarlos a GGUF:

```
[Correcciones manuales] ──┐
[Glosario de términos]  ──┼──> preparar_datos_v2.py ──> glosario_v2.jsonl
[Corpus de otros juegos] ──┘                                   │
                                                               ▼
                                                        entrenar_v2.py (Unsloth)
                                                               │
                                                               ▼
                                                     modelo_exportado_v2 (GGUF)
                                                               │
                                                               ▼
                                                     Ollama (IA_Traductora)
```

1. **Compilar el dataset**:
   ```bash
   python preparar_datos_v2.py
   ```
   Lee los diccionarios, códigos y correcciones de la carpeta `workspace/` y genera `datasets/glosario_v2.jsonl`.

2. **Entrenar con Unsloth**:
   ```bash
   python entrenar_v2.py
   ```
   Realiza el ajuste fino combinando el glosario especializado, el corpus bilingüe de videojuegos y ejemplos generales para evitar olvido catastrófico. Exporta el resultado a la carpeta `modelos/`.

3. **Cargar en Ollama**:
   ```bash
   ollama create IA_Traductora_v2 -f Modelfile
   ```

## ⚙️ Instalación y Requisitos

### Requisitos del Sistema:
* **Sistema Operativo:** Windows 10/11 o Linux.
* **GPU:** NVIDIA con soporte CUDA (recomendado 8 GB VRAM o superior para traducción con Ollama y entrenamiento con Unsloth).
* **Python:** 3.10 recomendado.
* **Ollama:** Instalado y en ejecución en `http://localhost:11434`.

### Instalación rápida (Windows):
Ejecuta el archivo [setup.bat](file:///j:/PythonAI/Traductor%20IA/setup.bat) en la consola:
```bat
setup.bat
```
Esto creará el entorno virtual `venv_traductor`, instalará PyTorch con CUDA 12.1, Unsloth, las librerías de aceleración (`xformers`, `bitsandbytes`, `peft`) y el servidor web Flask.

Para instalar utilidades adicionales de descompresión de partidas:
```bash
pip install lzstring
```
