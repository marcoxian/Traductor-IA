# Traductor de Videojuegos con IA Local

Este repositorio contiene un pipeline completo para traducir videojuegos automáticamente usando modelos de lenguaje (LLM) en local mediante Ollama y Unsloth. El flujo de trabajo está dividido en una secuencia de scripts numerados.

## 🚀 Flujo de Trabajo Principal

1. **`1_traducir_juego.py`**: Traduce los archivos CSV o de texto del juego usando el modelo local cargado en Ollama. Soporta reanudación y crea copias de seguridad automáticas (`.bak`).
2. **`2_generar_revision.py`**: Compara la traducción original con la nueva y genera un archivo CSV de revisión fácil de leer en Excel.
3. **`3_reparar_etiquetas_ia.py`**: Analiza la traducción para arreglar etiquetas rotas de código (ej. variables de colores, nombres en llaves `{Player}`) que la IA haya modificado por error.
4. **`4_aplicar_parches.py`**: Si editas manualmente algo en el CSV de revisión para corregirlo, este script lee esos cambios y los inyecta en los archivos traducidos definitivos.
5. **`5_traducir_nombres_personajes.py`**: Aplica un glosario específico para traducir y homogeneizar los nombres de los personajes que hablan en cada línea.

## 🛠️ Herramientas Extra y Minería de Datos

En la carpeta `herramientas_extra/` se encuentran scripts independientes para extraer traducciones oficiales de otros videojuegos. Estas frases bilingües se utilizan para **entrenar a la IA** en la jerga específica de los juegos.

- **`extraer_textos_juego.py`**: Extrae textos de las carpetas `Langs/` típicas de juegos en **GameMaker**.
- **`extraer_textos_renpy.py`**: Extrae diálogos bilingües de juegos de **Ren'Py** (requiere que los archivos `.rpy` estén descompilados usando *unrpyc*).
- **`extraer_textos_xunity.py`**: Parsea el archivo `AutoGeneratedTranslations.txt` generado por el parche **XUnity.AutoTranslator** en juegos de Unity.

Todas las frases extraídas con estas herramientas se guardan en la carpeta `corpus_videojuegos/`. 

## 🧠 Entrenamiento de la IA (Fine-tuning)

El script **`entrenar_v2.py`** coge el modelo base y lo re-entrena con:
- El glosario manual (`glosario_v2.jsonl`).
- Todo el corpus extraído de otros videojuegos (`corpus_videojuegos/*.jsonl` con peso doble).
- El dataset general de conocimiento (`dataset_base_general.jsonl`).

Una vez entrenado, el modelo resultante (`modelo_exportado_v2`) se puede exportar al formato GGUF ligero (16 bits o Q4) y montarlo de nuevo en Ollama para volver a ejecutar el paso 1 con una traducción mucho más técnica e inteligente.
