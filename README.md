# 🎮 Traductor de Videojuegos con IA Local

Pipeline integral y modular para la traducción asistida por Inteligencia Artificial local de videojuegos, diseñado para múltiples motores (**RPG Maker MV/MZ**, **Ren'Py**, **Unity / XUnity**, **GameMaker**, entre otros).

Utiliza Modelos de Lenguaje (LLMs) ejecutados en local mediante **Ollama** para la traducción en tiempo real, junto con un entorno de **Fine-Tuning con Unsloth** para entrenar modelos especializados en jerga de videojuegos, conservación de códigos de escape y coherencia contextual.

## 🎯 Perfiles de Juego en `workspace/<juego>/`

Para evitar mezclar el contexto de distintos videojuegos, el sistema busca automáticamente la carpeta `workspace/<nombre_juego>/` correspondiente:

- `glosario.json`: Reglas léxicas obligatorias exclusivas para ese juego.
- `contexto.txt`: Guía narrativa (género de protagonistas, tono, ambientación). Las líneas que comiencen con `#` se descartan automáticamente como comentarios.
- `nombres_protegidos.json`: Regex para restaurar nombres del juego que el LLM intente traducir literalmente.
- `nombres_propios.txt`: Lista de personajes propios para el paso 5.
- `nombres_hablantes.csv`: Tabla `ingles;correccion` de quién habla en los diálogos.

## 🚀 Flujo de Trabajo Principal

La tubería de traducción está organizada en pasos numerados para garantizar coherencia y control de calidad:

### 1. `1_traducir_juego.py` y `1_traducir_juego_turbo.py`
Envía los textos del juego a la IA local (vía Ollama).
```bash
# Modo seguro (frase a frase con historial de contexto)
python 1_traducir_juego.py --ruta "J:\Juegos\MiJuego" --modo seguro

# Modo turbo (en lotes de 20 con x7 velocidad)
python 1_traducir_juego.py --ruta "J:\Juegos\MiJuego" --modo turbo
# O directamente:
python 1_traducir_juego_turbo.py --ruta "J:\Juegos\MiJuego"

# Parámetros opcionales útiles:
#   --juego <nombre>     Indica el perfil en workspace/<nombre>
#   --archivo <nombre>   Traduce solo un archivo concreto (ej. System.json o Map012.json)
#   --modelo <nombre>    Modelo en Ollama (por defecto: IA_Traductora)
#   --motor <motor>      Forzar motor: RPGMaker, Godot, Unity, Unreal
```
* **Caché en disco:** Guarda automáticamente el progreso en `workspace/<juego>/cache/`. Si el proceso se detiene o se reinicia el PC, reanuda exactamente donde se quedó sin re-traducir frases ya completadas.
* **Ajuste visual de línea:** Corta los diálogos en pantalla respetando únicamente la longitud de los caracteres visibles (los códigos `\C[n]` o `\I[n]` no restan espacio en el bocadillo).
* **Copias de seguridad automáticas:** Genera respaldos `.bak` o `.original` de los archivos del juego antes de modificarlos.

### 2. `2_generar_revision.py`
Compara el archivo traducido con el original en inglés y genera un CSV estructurado (`revision_<juego>.csv`):
```bash
python 2_generar_revision.py --ruta "J:\Juegos\MiJuego"
```
Columnas: `archivo`, `linea`, `tag`, `problema`, `ingles`, `traduccion_ia` y `correccion`. Permite revisar y editar rápidamente en Excel o LibreOffice.

### 3. `3_reparar_etiquetas_ia.py`
Inspecciona la hoja de revisión en busca de errores sintácticos comunes de los LLMs (`ETIQUETAS`, `ORDEN`, `LONGITUD`):
```bash
python 3_reparar_etiquetas_ia.py --archivo revision_mi_juego.csv --modelo IA_Traductora
```
* Restaura automáticamente las etiquetas al formato original del motor usando un prompt de corrección técnico dedicado.

### 4. `4_aplicar_parches.py`
Inyecta tus correcciones en los archivos finales del juego:
```bash
python 4_aplicar_parches.py --ruta "J:\Juegos\MiJuego" --revision revision_mi_juego.csv
# O aplicando diccionarios globales:
python 4_aplicar_parches.py --ruta "J:\Juegos\MiJuego" --diccionario glosarios/glosario_interfaz_rpgmaker.csv
# Opción --resetear: devuelve al inglés únicamente las líneas con fallos no corregidas
```

### 5. `5_traducir_nombres_personajes.py`
Detecta los nombres de los personajes que hablan en los diálogos (`\N<\C[n]Nombre\C[0]>`) y aplica la tabla unificada:
```bash
python 5_traducir_nombres_personajes.py --ruta "J:\Juegos\MiJuego" --juego mi_juego
```

### 6. `6_auditoria_semantica.py`
Auditor de coherencia y falsos amigos. Corrige automáticamente errores típicos de traducción literal en videojuegos:
```bash
python 6_auditoria_semantica.py --ruta "J:\Juegos\MiJuego"
```
* `party` ➔ **grupo** (en lugar de *fiesta*).
* `item` ➔ **objeto** (en lugar de *elemento* o *artículo*).
* `save` ➔ **guardar** (en lugar de *ahorrar*).
* `miss` ➔ **fallo** (en lugar de *señorita*).
* `chest` (contenedor) ➔ **cofre** (en lugar de *pecho*).

### 7. `7_arreglar_partida_rpgmaker.py`
Herramienta de descompresión y edición en caliente de partidas guardadas de RPG Maker (`.rpgsave`):
```bash
python 7_arreglar_partida_rpgmaker.py --ruta "J:\Juegos\MiJuego"
```
* Descomprime el formato LZ-String en memoria.
* Aplica el diccionario y los reemplazos semánticos directamente en la partida guardada.
* Vuelve a comprimir la partida, permitiendo **probar las correcciones de inmediato sin tener que empezar una nueva partida**.

## 🧠 Entrenamiento de la IA (Fine-Tuning con Unsloth)

Para conseguir una traducción con calidad nativa y que no cometa errores con los códigos de control, el pipeline permite reentrenar modelos LLaMA / Mistral mediante LoRA y cuantizarlos a GGUF:

```
[Correcciones manuales] ──┐
[Glosario de términos]  ──┼──> preparar_datos_v2.py ──> glosario_v2.jsonl
[Corpus de otros juegos] ──┘                                   │
                                                               ▼
                                                        entrenar_v2.py (Unsloth)
                                                               │
                                                               ▼
                                                     modelo_exportado_v2 (GGUF)
                                                               │
                                                               ▼
                                                     Ollama (IA_Traductora)
```

1. **Compilar el dataset**:
   ```bash
   python preparar_datos_v2.py
   ```
   Lee los diccionarios, códigos y correcciones de la carpeta `workspace/` y genera `datasets/glosario_v2.jsonl` usando la misma plantilla canónica del traductor.

2. **Entrenar con Unsloth**:
   ```bash
   # Modo balanceado (~25-30 min en RTX 4070 - Recomendado):
   python entrenar_v2.py --modo balanceado

   # Modo completo (~2.5 horas):
   python entrenar_v2.py --modo completo
   ```
   Realiza el ajuste fino combinando el glosario especializado, el corpus bilingüe de videojuegos y ejemplos generales para evitar olvido catastrófico. Exporta el modelo cuantizado en formato GGUF `q4_k_m` a la carpeta `modelos/`.

3. **Cargar en Ollama y activar**:
   ```bash
   ollama create IA_Traductora_v2 -f Modelfile_v2
   ollama cp IA_Traductora_v2 IA_Traductora
   ```

## 🔔 Monitor en la Bandeja del Sistema (Estilo Steam / Discord)

Aplicación nativa de escritorio que se oculta discretamente en el área de notificación (junto al reloj de Windows):

* **Comportamiento en segundo plano:**
  * Al pulsar el botón **"Minimizar a la bandeja"**, la cruz de cierre o minimizar la ventana, esta se oculta completamente y **desaparece de la barra de tareas**.
  * Solo vuelve a abrirse si haces clic en el icono de la bandeja o ejecutas de nuevo la aplicación.
* **Icono dinámico y Tooltip:**
  * El icono dibuja en tiempo real un anillo de progreso con el porcentaje exacto (o símbolos de estado: ✔ terminado, ⏸ pausa, ! error).
  * Al **pasar el ratón por encima** del icono, muestra un tooltip con el juego, porcentaje, frases completadas, archivo actual y tiempo restante estimado (ETA).
* **Notificaciones de Windows:** Envía avisos automáticos al iniciar o terminar la traducción completa.

```bash
# Lanzar el monitor manualmente (abre la ventana):
iniciar_monitor_bandeja.bat
# o bien desde el acceso directo del Escritorio: "Traductor IA Monitor"

# Comportamiento automático:
# Cualquier traducción abre automáticamente la ventana del monitor por defecto:
python 1_traducir_juego.py --ruta "J:\Juegos\MiJuego" --modo turbo

# Opciones avanzadas de monitor al traducir:
#   --bandeja        Arranca el monitor directamente en la bandeja (sin mostrar la ventana)
#   --sin-monitor    No abre la aplicación del monitor (modo solo terminal)
```

Para monitorizar cualquier traducción en ejecución de forma visual desde el navegador:
```bash
python herramientas_extra/servidor_progreso.py
```

## 🛠️ Corrección y Auditoría en Vivo (RPG Maker MV)

Para revisar escenas reportadas en capturas de pantalla y corregir diálogos en caliente sin generar scripts temporales dispersos:

```bash
# 1. Buscar cualquier diálogo visto en pantalla (muestra hablante, emoción y original en inglés de .bak):
python herramientas_extra/gestor_rpgmaker.py buscar "frase o texto que ves en el juego"

# 2. Inspeccionar la escena completa en formato guión teatral bilingüe:
python herramientas_extra/gestor_rpgmaker.py inspeccionar --archivo Map012.json --evento 55

# 3. Aplicar corrección individual validada (crea backup automático y valida prefijos de 9 caracteres):
python herramientas_extra/gestor_rpgmaker.py parchear --archivo Map012.json --buscar "texto a reemplazar" --reemplazar "nuevo diálogo corregido"

# 4. O aplicar varias correcciones a la vez desde un archivo de lote JSON:
python herramientas_extra/gestor_rpgmaker.py parchear --lote parches.json
```
Todos los cambios quedan auditados automáticamente con fecha y descripción en `herramientas_extra/parches_aplicados.json`.

## ⚙️ Instalación y Requisitos

### Requisitos del Sistema:
* **Sistema Operativo:** Windows 10/11 o Linux.
* **GPU:** NVIDIA con soporte CUDA (recomendado 8 GB VRAM o superior para traducción con Ollama y entrenamiento con Unsloth).
* **Python:** 3.10 recomendado.
* **Ollama:** Instalado y en ejecución en `http://localhost:11434`.

### Instalación rápida (Windows):
Ejecuta el archivo [setup.bat](setup.bat) en la consola:
```bat
setup.bat
```
Esto creará el entorno virtual `venv_traductor`, instalará PyTorch con CUDA 12.1, Unsloth, las librerías de aceleración (`xformers`, `bitsandbytes`, `peft`) y el servidor web Flask.

Para instalar utilidades adicionales de descompresión de partidas:
```bash
pip install lzstring
```
